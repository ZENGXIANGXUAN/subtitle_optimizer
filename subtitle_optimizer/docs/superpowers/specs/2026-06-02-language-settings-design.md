# 语言设置功能设计

**日期**: 2026-06-02
**状态**: 已批准
**方案**: 方案 1 - 最小改动（语言作为 Prompt 参数）

---

## 1. 需求概述

在设置页面添加输入语言和输出语言配置，支持任意源语言到任意目标语言的翻译，并同步到 AI prompt 中。

**必须包含的语言**: 意大利语

---

## 2. 语言列表

预设 10 种常用语言，使用映射表格式：

| 显示标签 | 语言代码 | Prompt 名称 |
|---------|---------|------------|
| 中文 | zh | 中文 |
| English | en | English |
| 意大利语 (Italiano) | it | Italian |
| 日语 (日本語) | ja | Japanese |
| 韩语 (한국어) | ko | Korean |
| 法语 (Français) | fr | French |
| 德语 (Deutsch) | de | German |
| 西班牙语 (Español) | es | Spanish |
| 葡萄牙语 (Português) | pt | Portuguese |
| 俄语 (Русский) | ru | Russian |

**下拉框显示格式**: `中文名称 (原生名称)`
- 例如: `意大利语 (Italiano)`

---

## 3. UI 改动

在 API 设置页面的「原文行数」下方添加语言设置区域：

```
┌─────────────────────────────────────┐
│  原文行数                            │
│  原文在第几行：[第2行 ▼]              │
├─────────────────────────────────────┤
│  语言设置                            │
│  输入语言：[English ▼]               │
│  输出语言：[中文 ▼]                  │
└─────────────────────────────────────┘
```

**默认值**:
- 输入语言: English (en)
- 输出语言: 中文 (zh)

---

## 4. 配置持久化

在 `config.json` 中新增两个字段：

```json
{
  "api_key": "...",
  "base_url": "...",
  "model": "...",
  "concurrency": "6",
  "batch_size": "5",
  "original_line": 1,
  "glossary": "...",
  "input_language": "en",
  "output_language": "zh"
}
```

**向后兼容**: 如果配置文件中没有这两个字段，使用默认值 (en → zh)。

---

## 5. Prompt 改动

修改以下 4 个函数中的硬编码语言引用：

### 5.1 `_build_analysis_messages`
- 当前: 假设输入是英文，输出是中文
- 改为: 根据输入/输出语言动态调整描述

### 5.2 `_optimize_batch_impl`
- 当前: `"优化双语字幕的中文翻译"` / `"将英文字幕翻译成中文"`
- 改为: `"优化双语字幕的{输出语言}翻译"` / `"将{输入语言}字幕翻译成{输出语言}"`

### 5.3 `_translate_batch_impl`
- 当前: `"将英文字幕翻译成中文"`
- 改为: `"将{输入语言}字幕翻译成{输出语言}"`

### 5.4 `BatchWorker` 和 `SegmentWorker` 中的提示
- 当前: `"检测到原生字幕，将自动翻译为中文"`
- 改为: `"检测到原生字幕，将自动翻译为{输出语言}"`

---

## 6. SubtitleEntry 属性

保留现有属性不变：
- `chinese`: 检测是否有中文字符（Unicode `一-鿿`）
- `english`: 检测是否有非中文字符

**理由**:
- 这些属性用于检测字幕中是否已有中文（判断是否是双语字幕）
- 与语言设置无关，可以保留

---

## 7. 特殊场景处理

### 7.1 输入语言 = 输出语言
- 例如: English → English
- 处理: 跳过翻译阶段，只做优化润色
- 日志提示: `"输入输出语言相同，跳过翻译，仅优化"`

### 7.2 原生字幕检测
- 当前逻辑: `len(entry.lines) == 1` → 原生字幕
- 保持不变，与语言设置无关

### 7.3 双语字幕提取
- 当前逻辑: 根据 `original_line` 提取原文行
- 保持不变，提取后变成单语言字幕

### 7.4 输出格式
- 始终输出: 目标语言 + 原文（双语）
- 与当前行为一致
